# Runtime source snapshot

These files document the original Steerability/Inspect integration. `research_pipeline.py` applies state changes, `preparatory_inspect.py` records execution, `reused_model.py` restores sequential conditions, and `direction_construction.py` records construction. The repository source manifest checks the distributed files.

This snapshot omits model weights and a complete runtime dependency tree. For generation setup and qualification, see [GPU setup](../../docs/GPU_SETUP.md). The default notebook uses saved records.
